## Notes (paste into "Notes")

```
Unalome Pocket runs open AI language models entirely on the device. There is no account, no login and no server of ours.

HOW TO TEST QUICKLY
1. Open the app and go through the three onboarding screens.
2. On a device with Apple Intelligence, choose "Start now with the built-in model". No download is needed and you can chat immediately.
3. Otherwise choose "Qwen 3.5 0.8B" (about 650 MB, the smallest model) and tap Download. Wi-Fi is recommended. When it finishes, type a message.
4. After a model is installed the app works in airplane mode.

NETWORK USE
The only network requests are model file downloads from huggingface.co, started by the user. Chat content never leaves the device. The app contains no analytics, advertising or crash-reporting SDK.

DOWNLOADED MODELS (2.5.2)
Models are weight files (data) run by the MLX framework compiled into the app. No downloaded file is executed as code and no app feature is changed by a download.

AI-GENERATED CONTENT (1.2)
- A notice under the chat states that answers are AI-generated and may be wrong.
- Every reply has a "Report this response" action, which opens an email to support@unalome.ai.
- The bundled personas are general purpose.

PERMISSIONS
- Microphone and Speech Recognition: optional dictation, processed on device.
- Camera and Photos: optional, to attach an image for a vision-capable model.

MEMORY
The app uses the Increased Memory Limit entitlement because language models are large. It checks available memory before loading a model and recommends models that fit the device.

BACKGROUND
Model downloads can continue in the background with a Live Activity showing progress. Text generation stops when the app leaves the foreground.

OPEN SOURCE
Source code, Apache 2.0: https://github.com/unalome-ai/unalome-pocket
```
